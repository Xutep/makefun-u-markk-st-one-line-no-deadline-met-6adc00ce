# One Line, No Deadline Met

Entry for the [make.fun bounty](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce): a program that writes one single-line joke giving an excuse for a missed deadline (max 200 characters) to `/output/entry.txt`.

The joke:

> The deadline texted me 'we need to talk' and I've been avoiding it ever since.

Run it with `python3 main.py` (stdlib only, deterministic — same line every run).
